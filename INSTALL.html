Use your existing browser login

Install the local extension once in the Chrome or Firefox profile where you already use LinkedIn. After that, click its toolbar icon, paste profile links, and send.

Chrome

  1. Open chrome://extensions and turn on Developer mode.
  2. Click Load unpacked and select the extension folder beside this file.
  3. Click the Local Connection Queue icon from Chrome’s Extensions menu.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and select extension/manifest.json beside this file.
  3. Click the Local Connection Queue icon from Firefox’s Extensions menu. Grant LinkedIn access if Firefox asks.

Firefox temporary add-ons need to be loaded again after Firefox restarts.

Then just paste links

The extension opens the same HTML page in your current browser. There is no separate login, browser profile, Python server, or terminal to keep running. Keep the queue page open while requests are processing. Preview checks without sending.

Already installed? Update it

Reload Local Connection Queue in your browser’s extension manager, close the old queue page, then click the extension icon again. The footer should show v0.2.6. Use Preview first. Keep both the queue page and the LinkedIn tab open.

LinkedIn prohibits automated invitations and may restrict your account. Official rules. Real signed-in sending still needs a live check.
